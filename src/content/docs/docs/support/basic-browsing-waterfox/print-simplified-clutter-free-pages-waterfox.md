title: "Print simplified, clutter-free pages in Waterfox"
---

Waterfox lets you print pages in a simplified format that strips away clutter like buttons, ads, and background images, for better readability and paper/ink savings.

- For more information on printing in Waterfox, see [How to print web pages in Waterfox](/support/how-print-web-pages-waterfox).

To get a print-friendly view, turn on [Reader View](/support/waterfox-reader-view-clutter-free-web-pages) for the page before printing:
![Before and after Simplify page](/assets/docs/2017-12-07-14-03-25-440c58.png)

1. If a page is available in Reader View, the Reader View icon <img alt="reader mode icon" class="inline-image" src="/assets/docs/icons/reader-mode.svg" /> will appear in the address bar.
   <img alt="Fx78URLbar-ReaderViewIcon" class="inline-image" src="/assets/docs/2021-06-06-04-50-28-4aec64.png">
2. Click on the Reader View icon <img alt="reader mode icon" class="inline-image" src="/assets/docs/icons/reader-mode.svg" />. The icon will turn blue when the page is in Reader View.
3. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> to open the menu panel.
4. Click Print to preview the page and print it.
