Use Find in Page to search for words or links on the page you’re viewing.

## Open Find in Page

- Keyboard: Ctrl+F (Windows/Linux) or Command+F (macOS).
- Menu: Edit > Find in Page.

The find bar appears with a search field and options.

## Search options

- Highlight All: Highlights all matches on the page.
- Match Case: Matches uppercase/lowercase exactly.
- Whole Words: Matches only whole words.
- Links only: Finds only text that is part of a link.

Use Enter/Return or the up/down arrows in the find bar to jump between matches.

## Tips

- Select text on the page and press Ctrl+F/Command+F to search for the selection.
- Use the status indicator in the find bar (for example, 3/10) to see your position among matches.
