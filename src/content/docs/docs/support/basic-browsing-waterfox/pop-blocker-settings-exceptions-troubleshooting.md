---

Waterfox blocks most pop-up windows by default. You can control this behavior and allow pop-ups for trusted sites.

## Change pop-up settings

1. Open Settings > Privacy & Security.
2. Under Permissions, check Block pop-up windows to enable blocking.
3. Click Exceptions to allow pop-ups on specific sites you trust.

## Allow pop-ups for a site

1. Visit the site.
2. Use the site information panel (lock icon) or go to Settings > Privacy & Security > Permissions > Exceptions for Pop-ups.
3. Add the site and allow pop-ups.

## Troubleshooting

- Pop-ups still appear
  - They may be triggered by scripts that open in the current tab or by malicious sites. Consider using a reputable content blocker.
- A site requires pop-ups to function (payments, forms)
  - Add the site to Exceptions as described above.
- A blocked pop-up is needed
  - Look for a notification in the address bar and choose to allow pop-ups for the site.
