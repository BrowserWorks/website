Reader View is a Waterfox feature that strips away clutter like buttons, ads, background images, and videos while also letting you customize the layout and theme to fit your reading preferences.

## View a page in Reader View

1. If a page is available in Reader View, the Reader View icon <img alt="reader mode icon" class="inline-image" src="/assets/docs/icons/reader-mode.svg" /> will appear in the address bar.
   <img alt="URL bar with Reader view icon highlighted" class="inline-image" src="/assets/docs/2021-06-06-00-18-26-f1467f.png">
2. Click on the Reader View icon <img alt="reader mode icon" class="inline-image" src="/assets/docs/icons/reader-mode.svg" />; a blue version of the icon indicates the feature is currently active.

:::tip
If a page is available in Reader View, you can also access Reader View from the Menu bar [when the Menu bar is enabled](/support/restore-menu-bar-waterfox), by clicking View then Enter Reader View. Alternatively, you can press the key F9 to toggle Reader View.
:::

## Modify Reader View settings

Options are available to the left of the article content:

![Reader view settings](/assets/docs/2021-06-06-00-31-47-f1467f.png)

Reader View options:

<img alt="close icon" class="inline-image" src="/assets/docs/icons/close.svg" />: Exit Reader View.

<img alt="reader mode type control" class="inline-image" src="/assets/docs/icons/rm-type-control.svg" />: Adjust the layout (text font and size, content width, line height) and theme (light, sepia, dark) in Reader View.

<img alt="narrate icon" class="inline-image" src="/assets/docs/icons/narrate.svg" />: Have Waterfox read an article out loud in Reader View.

This option will show up only if Windows has [Text-to-speech](https://en.wikipedia.org/wiki/Speech_synthesis) information in the language that the article is in.
