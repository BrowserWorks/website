---

When you type in the address bar, results include actions you can take from a result’s three‑dot menu.

## Open the result menu

- Start typing in the address bar and hover a result.
- Click the three‑dot menu next to a result to see available actions.

## Common actions

- Open in new tab or new window.
- Dismiss this result.
- Remove from history (for history items).
- Edit or remove bookmark (for bookmarks).
- Pin or unpin top site (for top sites/shortcuts).

## Control what appears

- Manage which sources appear in results (history, bookmarks, open tabs, suggestions) in Settings > Privacy & Security > Address Bar.
- For suggestion details and controls, see [Waterfox Suggest FAQ](/support/waterfox-suggest-faq).
