Bookmarks let you save and organize pages you want to visit again. This guide covers the basics of creating, finding, and managing bookmarks in Waterfox.

## Create a bookmark

- Click the star in the address bar. The page is saved to your Bookmarks.
- Click the star again to edit the name, choose a folder, or add tags.

Shortcuts:
- Windows/Linux: Ctrl+D to add a bookmark; Ctrl+Shift+O to open the Library.
- macOS: Command+D to add a bookmark; Command+Shift+O to open the Library.

## Find your bookmarks

- Bookmarks Toolbar: Show favorite sites under the address bar. See [Bookmarks toolbar — display your favorite websites](/support/bookmarks-toolbar-display-favorite-websites).
- Bookmarks Menu: Open from the menu button > Bookmarks.
- Library: Menu > Bookmarks > Manage Bookmarks to open the Library window for full management.
- Address bar: Start typing; Waterfox suggests matches from bookmarks, history, and open tabs. See [Address bar autocomplete suggestions in Waterfox](/support/address-bar-autocomplete-waterfox).

## Organize bookmarks

- Use folders in the Library to keep related bookmarks together.
- Drag and drop to reorder or move bookmarks between folders.
- Add tags to group bookmarks across folders and search by tag.
- To remove a bookmark, click the star and choose Remove Bookmark, or delete it from the Library.

## Import or export bookmarks

- Import from another browser: See [Import data from another browser](/support/import-data-another-browser).
- Import from an HTML file: See [Import Bookmarks from an HTML file](/support/import-bookmarks-html-file).
- Export to HTML for backup or transfer: See [Export Waterfox bookmarks to an HTML file](/support/export-waterfox-bookmarks-to-backup-or-transfer).
- Restore from backup or move to another computer: See [Restore bookmarks from backup or move them](/support/restore-bookmarks-from-backup-or-move-them).

## Tips

- Pin frequently used sites to the Bookmarks Toolbar for one‑click access.
- Use meaningful names and tags to make searching faster.
- Right‑click a bookmark or folder to open in a new tab, edit, copy, or delete.
