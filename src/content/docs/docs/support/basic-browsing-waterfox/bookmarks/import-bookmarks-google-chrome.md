---

You can bring your bookmarks from Google Chrome into Waterfox in just a few steps. You can do this at first‑run or any time from Waterfox settings.

:::tip
To import more than bookmarks (such as history, passwords, or cookies), see [Import data from another browser](/support/import-data-another-browser).
:::

## Import from Chrome (Windows, macOS, Linux)

1) Open the Import wizard
- Click the menu button <img alt="menu" class="inline-image" src="/assets/docs/icons/menu.svg" /> > Settings.
- In the General panel, open Import Data or Import from Another Browser.

2) Choose Google Chrome
- If Chrome has multiple profiles, pick the one you want.

3) Select what to import
- Choose Bookmarks (and any other items you want to import if available).

4) Finish
- Click Import and wait for the confirmation.

## Where to find your imported bookmarks

- Waterfox places imported bookmarks in a folder named “From Google Chrome” inside your Bookmarks Menu. You can reorganize them at any time.
- Manage bookmarks from the Library: open the menu > Bookmarks > Manage Bookmarks (or press Ctrl+Shift+O on Windows/Linux, Command+Shift+O on macOS).

## Troubleshooting

- Chrome is running
  - Close Google Chrome completely and try the import again.
- The wrong Chrome profile was used
  - Run the import again and select the correct Chrome profile.
- I only have an HTML export
  - If you exported an HTML file from Chrome, see [Import Bookmarks from an HTML file](/support/import-bookmarks-html-file).
