---

On Windows and macOS, you can import your bookmarks from Microsoft Edge into Waterfox. When available, you can also import history, passwords, cookies, and more.

:::tip
For a full overview of importing from other browsers, including extensions, see [Import data from another browser](/support/import-data-another-browser).
:::

## Import from Microsoft Edge (Windows, macOS)

1) Open the Import wizard
- Click the menu button <img alt="menu" class="inline-image" src="/assets/docs/icons/menu.svg" /> > Settings.
- In the General panel, open Import Data or Import from Another Browser.

2) Choose Microsoft Edge
- If Edge has multiple profiles, pick the one you want.

3) Select what to import
- Choose Bookmarks/Favorites (and any other items you want to import if available).

4) Finish
- Click Import and wait for the confirmation.

## Import from Internet Explorer (Windows)

If you still have Internet Explorer data on an older Windows system, Waterfox can import bookmarks (Favorites) and other supported items.

1) Open the Import wizard from Settings as above.
2) Choose Internet Explorer.
3) Select the items to import and click Import.

## Where your imported Favorites appear

- Waterfox places imported Favorites in a folder named “From Microsoft Edge” or “From Internet Explorer” within your Bookmarks Menu. You can reorganize them any time.
- Manage bookmarks from the Library: menu > Bookmarks > Manage Bookmarks (Ctrl+Shift+O on Windows, Command+Shift+O on macOS).

## Troubleshooting

- Edge or Internet Explorer is running
  - Close the source browser completely before importing.
- The expected profile is missing
  - If Edge has multiple profiles, run the import again and select the correct profile.
- Only have an HTML export
  - If you exported an HTML file, see [Import Bookmarks from an HTML file](/support/import-bookmarks-html-file).
