The [New Tab page](/support/about-new-tab-page) is the default home page that opens when you start Waterfox, click the Home icon <img alt="Home Button 57" class="inline-image" src="/assets/docs/2017-10-19-01-59-26-fcbbdc.png"> in the toolbar or open a new window. This article explains how to set your Waterfox home page.

- If you want Waterfox to open the windows and tabs from your previous session each time you start Waterfox, instead of opening your home page, see [Configuring session restore](/support/restore-previous-session#configuring-session-restore).

## Set or change your home page through the Home button

1. Open the web page you want to use as your home page.
2. Drag and drop that tab onto the Home icon <img alt="Home Button 57" class="inline-image" src="/assets/docs/2017-10-19-01-59-26-fcbbdc.png"> on your toolbar.
   ![Dragging Home Page 57](/assets/docs/2017-10-19-02-02-07-86574c.png)
3. Click Yes on the prompt to set this page as your home page.

## Set your home page through Waterfox Settings

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> and select Settings.
2. Click the Home panel.
   ![Fx91HomePanel](/assets/docs/2022-02-03-04-41-57-dc1fe9.png)
3. Click the menu next to _Homepage and new windows_ and choose to show the default Waterfox Home page, custom URLs or a blank page.

### Set multiple pages as your home page

You can set a group of pages as your home page. Open each page in a separate tab, select Custom URLs… in the _Homepage and new windows_ drop-down menu and click on Use Current Pages*.
![Fx91HomePanel-CustomURLs](/assets/docs/2022-02-03-04-48-41-8baafe.png)*

## Having problems?

We have solutions:

- If you keep getting the "Waterfox has just updated" tab every time Waterfox starts, see the article [Waterfox says it's just updated every time it starts - how to fix](/support/waterfox-says-its-just-updated-every-time-it-starts).
- If your home page settings are not saved, see [How to fix preferences that won't save](/support/how-to-fix-preferences-wont-save).
- If you don't see the Home button, have a look at [Customize Waterfox controls, buttons and toolbars](/support/customize-waterfox-controls-buttons-and-toolbars).
- If your home page was hijacked or automatically changed, see [Remove a toolbar that has taken over your Waterfox search or home page](/support/remove-toolbar-has-taken-over-your-waterfox-search).

- It's possible the shortcut you are using to open Waterfox has a link in it. Right-click on the shortcut and check. See [Wrong home page opens when I start Waterfox - How to fix](/support/wrong-home-page-opens-when-i-start-waterfox-how-fix) for details.

- An extension may be controlling your home page. For more information, see [An extension changed my New Tab page or home page](/support/extension-changed-my-new-tab-page).
