---

Waterfox lets you display menus, notifications, messages and other parts of the Waterfox interface in different languages.

:::tip
To choose a language for displaying web pages, see [Choose display languages for multilingual web pages](/support/choose-display-languages-multilingual-web-pages).
:::

## Switch Waterfox to another language

You can switch languages at any time to display Waterfox menus, notifications and messages in a different language.

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> and select Settings.
2. In the _Language_ section of the General panel, choose a language in the drop-down menu.
3. Restart Waterfox.

## Add languages to the Waterfox interface

Follow these steps to add more languages to Waterfox.

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> and select Settings.
2. In the _Language_ section of the General panel, click Search for more languages in the drop-down menu.
3. Click Select more languages to add and choose the languages you want to add, then click the Add button.
4. Use the Move Up and Move Down buttons to change the order or Remove to remove a language from the list.
5. Click OK to save your changes.

Waterfox will display the first language as your default and will display alternate languages if necessary in the order they appear.

## Set an order of preference for languages

If a Waterfox feature is not available in your top language, Waterfox will display your next preferred language.

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> and select Settings.
2. In the _Language_ section, click Set Alternatives to open the _Waterfox Language Settings_ window.
3. Select a language and use the Move Up and Move Down buttons to change the order or Remove to remove a language from the list.
