---

Some extensions can manage or hide tabs (for example, tab managers or vertical tab extensions). If tabs seem to disappear, they may be controlled by an extension.

## Show hidden tabs

1. Open Menu > Add-ons and themes > Extensions.
2. Disable the tab‑related extension to restore default tab behavior.
3. Re‑enable it and check the extension’s settings to adjust how it groups or hides tabs.

Tip: Some extensions add a sidebar or toolbar button to switch tab views or groups.
