---

To protect your privacy and security, some browsers restrict extensions from running on certain sensitive domains. This helps prevent extensions from intercepting credentials or altering critical pages.

In Waterfox, extension behavior on sensitive domains may be limited for safety. If an extension doesn’t run on a particular site, you’ll see a notice in the extension’s menu.

## What you can do

- If the extension supports site permissions, open its menu to see details.
- Contact the extension developer if you need a site supported.
