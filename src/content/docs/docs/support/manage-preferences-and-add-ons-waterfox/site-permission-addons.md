---

Some features on the web require special components, such as media codecs or DRM modules. Waterfox installs and updates certain site permission add-ons to enable these features when needed.

Examples:
- OpenH264 video codec for WebRTC calls. See [OpenH264 plugin for Waterfox](/support/open-h264-plugin-waterfox).
- DRM for protected video (Widevine) when enabled. See [Watch DRM content in Waterfox](/support/drm-content).

## Manage site permission add-ons

- Open Menu > Add-ons and themes > Plugins (or Components) to view status.
- Waterfox updates these components automatically. You can disable them, but some sites may not work correctly.

## Privacy

- These components only activate when required by a site feature (for example, DRM video playback or WebRTC).
- You control permissions per site from the site information panel (lock icon) and Settings > Privacy & Security.
