title: "Restore the Menu bar in Waterfox"
---

The _File Edit View History Bookmarks Tools Help_ Menu bar in Waterfox is hidden by default. It's also missing when Waterfox is in full screen mode or if the file storing your toolbar information has become corrupt. We'll show you how to fix each of these.

## Show the Menu bar

**Don't need to see the Menu bar all the time?** Press the Alt key to temporarily show the Menu bar. (If the Alt key doesn't work, press the AltGr key.)
To always show the Menu bar:

- Right-click the top of the Waterfox window and click Menu bar.

Alternatively:

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" />, click More Tools… and choose Customize Toolbar….
   - A new _Customize Waterfox_ tab will open.
2. Click Toolbars at the bottom of the window and click Menu Bar.
   ![menu bar customize 57](/assets/docs/2017-10-30-23-53-11-11ab4c.png)
3. Click Done to save your changes.

## Turn off full screen mode

Here's how to turn off full screen mode so you can see the Menu bar again.

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> on the right side of the toolbar.
2. Click the full screen icon <img alt="fullscreen menu button 57" class="inline-image" src="/assets/docs/2017-10-31-00-14-47-618a43.png">.
   ![fullscreen menu 57](/assets/docs/2017-10-31-00-16-42-646d8f.png)

## Fix corrupted toolbars and controls

If the file storing your toolbar information has become corrupt, you can use the _Refresh Waterfox_ feature to restore the default toolbar settings and controls.
See [Refresh Waterfox - reset add-ons and settings](/support/refresh-waterfox-reset-add-ons-and-settings).
