---

If a setting says it’s controlled by an extension, a browser add-on has taken ownership of that preference.

## Restore control

1. Open Menu > Add-ons and themes > Extensions.
2. Find the extension listed next to the message.
3. Click the three‑dot menu and disable or remove it.
4. Return to Settings and adjust the preference.

Notes:
- Some extensions change your Home page, New Tab page, search settings, or proxy settings.
- If you trust the extension, you can keep it enabled and configure options within the extension instead.
