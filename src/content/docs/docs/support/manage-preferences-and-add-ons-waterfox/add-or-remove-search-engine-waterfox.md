---

Waterfox comes with a number of available search engines by default. Many websites offer search engines that you can add to Waterfox. This allows you to search with that website's search engine, directly from your Waterfox address bar or Search bar. This article explains how to add or remove the search engines that Waterfox uses.

- To change your default search engine or other search settings, see [Change your default search settings in Waterfox](/support/change-your-default-search-settings-waterfox).
- To learn about using search engine keywords, see [Assign shortcuts to search engines](/support/assign-shortcuts-search-engines).

## Add search engines

:::note
If you removed one of the [default search engines](/support/change-your-default-search-settings-waterfox#default-search-engine) built into Waterfox, such as Google, you can restore the default search engines in your Waterfox Options
to add it back. See [Remove search engines](#remove-search-engines) and [Adding back a removed search engine](#adding-back-a-removed-search-engine), below.
:::

### Add a search engine from the Search bar

Waterfox offers an optional Search bar. See [Add the Search bar to your Waterfox toolbar](/support/add-search-bar-waterfox-toolbar) to add it to Waterfox.

1. Visit a website that offers an [OpenSearch](https://developer.mozilla.org/docs/Web/OpenSearch) search engine (we'll use [YouTube](https://www.youtube.com) as an example).
2. Click the magnifying glass ![addsearch 40](/assets/docs/2015-08-04-10-25-59-77093e.png) icon in the Search bar.
3. Click on the YouTube <img alt="AddYouTubeSearchBarIcon" class="inline-image" src="/assets/docs/2022-02-22-03-40-25-7be19c.png"> icon in the Search bar drop-down.
   ![Fx91SearchBar-AddYouTube](/assets/docs/2022-02-21-17-10-11-f135e2.png)

The search engine will appear in your available search options.

### Add a search engine from the address bar

When you visit a website that offers an [OpenSearch](https://developer.mozilla.org/docs/Web/OpenSearch) search engine, you can add it from the address bar context menu (we'll use [YouTube](https://www.youtube.com) as an example).

1. Right-click
   on the address bar.
   ![Fx89AddSearchEngine](/assets/docs/2021-04-19-03-10-39-50664c.png)
2. Select Add "YouTube" from the context menu.

### Mycroft Project search engine plugins

The [Mycroft Project](https://mycroftproject.com/) website offers search engine plugins. When you click on an available search plugin, you can add it to Waterfox from the Search bar or from the address bar context menu, on the _Install plugin_ page.

![Fx97InstallMycroftSearchEngine](/assets/docs/2022-02-21-12-23-19-e27e64.png)

### Search engine add-ons

Many providers offer search engine add-ons. To find these search engines and add them to Waterfox:

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> and select Settings.
2. In the Options
   tab that opens, click on Search in the left pane.

   :::tip
   If you added the optional Search bar, another way to open the Search panel is to click the magnifying glass <img alt="MagnifyingGlass](/assets/docs/2019-09-07-15-46-20-c45e06.png) on the Search bar and then click the ![Fx89Personalize-GearIcon" class="inline-image" src="/assets/docs/2021-05-13-16-54-32-4742a0.png"> _Change search settings_ icon.
   :::

3. At the bottom of the Search panel, click on the _Find more search engines_ link. The _Waterfox Add-ons_ website will open.
4. Select the search engine add-on you want to install and click Add to Waterfox.

## Hide search engines

Follow these steps to remove alternative search engines you don't want to use.

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> and select Settings.
2. In the Options
   tab that opens, click on Search in the left pane.

   :::tip
   If you added the optional Search bar, another way to open the Search panel is to click the magnifying glass <img alt="MagnifyingGlass](/assets/docs/2019-09-07-15-46-20-c45e06.png) on the Search bar and then click the ![Fx89Personalize-GearIcon" class="inline-image" src="/assets/docs/2021-05-13-16-54-32-4742a0.png"> _Change search settings_ icon.
   :::

3. Under _Search Shortcuts_, remove the check mark next to each search engine you don't want to use.
   ![Fx83settings-HideSearchEngine](/assets/docs/2020-11-03-12-09-04-074a48.png)

## Remove search engines

To remove a search engine, follow these steps:

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> and select Settings.
2. In the Options
   tab that opens, click on Search in the left pane.

   :::tip
   If you added the optional Search bar, another way to open the Search panel is to click the magnifying glass <img alt="MagnifyingGlass](/assets/docs/2019-09-07-15-46-20-c45e06.png) on the Search bar and then click the ![Fx89Personalize-GearIcon" class="inline-image" src="/assets/docs/2021-05-13-16-54-32-4742a0.png"> _Change search settings_ icon.
   :::

3. Under _Search Shortcuts_, click on the search engine you want to remove.
   ![Fx83settings-RemoveSearchEngine](/assets/docs/2020-11-03-12-10-12-dab4f4.png)
4. Click the Remove button to take it off your list.

:::note
If a search engine is added back after you restart Waterfox, it may be a Waterfox [extension](/support/find-and-install-add-ons-add-features-to-waterfox#what-types-of-add-ons-can-i-install). Those can be removed using the **Add-ons manager** (see [Disable or remove Add-ons](/support/disable-or-remove-add-ons) for details).
:::

### Adding back a removed search engine

If you remove a search engine that you added yourself and you change your mind, you'll have to add it back again, either from the [Search bar](#add-a-search-engine-from-the-search-bar) or [address bar](#add-a-search-engine-from-the-address-bar) by visiting the website or by reinstalling the [Search engine add-on](#search-engine-add-ons) (see above).

If you remove any of the default search engines that are built into Waterfox, you'll have to go to your Waterfox Options
Search panel and click the Restore Default Search Engines button in the _Search Shortcuts_ section to bring them back.
