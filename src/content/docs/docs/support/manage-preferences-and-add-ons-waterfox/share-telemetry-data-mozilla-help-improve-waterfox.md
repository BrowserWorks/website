title: "Share telemetry data with BrowserWorks to help improve Waterfox"
---

Waterfox does not collect or send telemetry.

- All telemetry code paths are disabled at the browser level.
- There are no settings to enable telemetry or participation in product studies.
- The about:telemetry page will show no collected measurements.
