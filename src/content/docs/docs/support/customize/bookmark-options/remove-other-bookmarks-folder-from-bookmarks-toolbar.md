---

Your bookmarks Library contains a folder called "_Other Bookmarks_". (To learn more, see the [Bookmarks in Waterfox](/support/bookmarks-waterfox) article.) An _Other Bookmarks_ folder will appear at the end of the [Bookmarks toolbar](/support/bookmarks-toolbar-display-favorite-websites) if the "_Other Bookmarks_" folder in your Library contains any bookmarks. This is done to make it easier to find bookmarks stored in this folder.

If you'd like to remove the _Other Bookmarks_ folder from the Bookmarks toolbar, use these instructions:

1. Right-click
   on a blank spot in the Bookmarks toolbar (or on the _Other Bookmarks_ folder icon) to open the context menu.
   ![Fx85BookmarksToolbarContextMenu](/assets/docs/2021-01-10-03-00-28-3109a8.png)
2. Click on the Show Other Bookmarks menu item to remove the check mark.
