[Add-ons](https://addons.mozilla.org/firefox/) allow you to add extra features and functionality to Waterfox. If you need help installing add-ons, see [Find and install add-ons to add features to Waterfox](/support/find-and-install-add-ons-add-features-to-waterfox).

For fixes and new features, keep your add-ons up to date. Here's how to update your add-ons.

## Updating add-ons

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" />, click Add-ons and Themes and select Extensions.
2. Click the gear icon <img alt="gear" class="inline-image" src="/assets/docs/icons/settings.svg" /> in the upper-right area of the Extensions panel.
   ![update addons 57](/assets/docs/2017-11-03-03-05-10-e426b1.png)
3. Choose one of the options below:

- **Check for Updates:** Allows you to check for any updates to your add-ons manually. If there is an update available, you have the option to choose to update it now or later.
- **View Recent Updates:** When you click this option, a Recent Updates panel appears on the left, showing your last updated add-ons.
- **Update Add-ons Automatically:** If you want to keep your add-ons up to date, select this option to let them update automatically.
- **Reset All Add-ons to Update Automatically:** If any add-ons have been set to update manually, clicking this option will reset all add-ons to update automatically.

### Update settings for specific add-ons

**Warning**: Turning off automatic updates might make you miss important security updates to your installed add-ons. We recommend that if you don't use an add-on, [disable it](/support/disable-or-remove-add-ons#how-to-disable-extensions-and-themes) instead of turning off automatic updates.
You can individually adjust the update method for each extension as follows, when the recommended _Update Add-ons Automatically_ option has been selected:

1. Go to the Extensions panel.
2. Click **More** to see the details page of a specific extension.
3. Find the _Automatic Updates_ line. (You may need to scroll down the page).

   - Select **Off** to set manual updates for that extension. When automatic updates are turned off, a _Check for Updates_ link will appear on the same line.

   - Select **On** or **Default** to set the extension to update automatically.

4. If you want, you can go back to the Extensions panel to set up others.
5. Close the Add-ons Manager (about:addons) tab.

### Can I update legacy add-ons?

Extensions that do not meet [Waterfox's new add-on technology](/support/waterfox-add-technology-modernizing) have been deactivated and moved to the Legacy Extensions panel. If you need the add-on, you can visit the developer's website to see if it will be migrated to the [WebExtensions](https://developer.mozilla.org/Add-ons/WebExtensions/What_are_WebExtensions) standard. The extension will automatically update when the add-on developer provides a compatible version. You can also follow these instructions to look for a replacement:

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" />, click Add-ons and Themes and select Legacy Extensions.

2. Click the Find a Replacement button to the right of the add-on. If a replacement isn't available, the Featured Add-ons page will open, where you can search for a compatible alternative. The [Extension Finder](https://mozilla.github.io/extension-finder/) utility can also help you find replacement extensions.
