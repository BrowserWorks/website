Extensions are a type of Waterfox add-on. This article describes how to find, install and manage extensions in Waterfox.

## What are extensions?

Extensions are Waterfox add-ons that provide additional functionality to Waterfox.

People all over the world have developed thousands of extensions for Waterfox. There are extensions that allow you to block advertisements, download videos from websites, integrate more closely with websites like Facebook or Twitter, and add features you see in other browsers.

## How to install extensions

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" />, click Add-ons and Themes and select Get Add-ons.
   - You can also search for specific extensions by using the search box at the top.
2. After finding an extension, click on the 'Add to Firefox' button.
3. Waterfox will download the requested extension and may ask you to confirm that you want to install it.

## Managing extensions

### How to change extension settings

Some extensions have settings you can change.

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" />, click Add-ons and Themes and select Extensions .
2. Select the extension you want to edit.
3. Click the Options button.
   - If the Options button is not available, the extension does not offer settings to change.

### How to disable or remove extensions

If you select an extension in the Add-ons Manager's Extensions panel, you can click Disable to turn it off or to remove it. For more information, see [Disable or remove Add-ons](/support/disable-or-remove-add-ons).

## Troubleshooting

- If you have problems with Waterfox, they may be caused by an extension or combination of extensions. For help on how to diagnose extension problems, see [Troubleshoot extensions, themes and hardware acceleration issues to solve common Waterfox problems](/support/troubleshoot-extensions-themes-to-fix-problems).
- If you cannot install an extension, see [Unable to install add-ons (extensions or themes)](/support/unable-install-add-ons-extensions-or-themes).
