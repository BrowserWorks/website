title: "Why is there an OpenH264 plugin in Waterfox?"
---

Many streaming videos rely on the H.264 codec in order to work. Because of licensing restrictions, H.264 is not available for open source software like Waterfox. Instead, Waterfox uses its open source alternative, [OpenH264](http://www.openh364.org/), to support video calls.

OpenH264 is released in collaboration with Cisco and Waterfox. It is automatically installed by Waterfox on your Waterfox browser to enable video calls with devices that require the [H.264](http://en.wikipedia.org/wiki/H.264/MPEG-4_AVC) codec.
