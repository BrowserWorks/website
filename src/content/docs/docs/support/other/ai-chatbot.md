---

Waterfox does not include a built‑in AI chatbot integration. If you want AI assistance in the browser, you can install a compatible extension from Firefox Add-ons.

## Add an AI chatbot extension

1. Visit Firefox Add-ons and search for the AI service you prefer.
2. Install the extension and review its permissions.
3. Open the extension’s settings to sign in and configure behavior.

## Privacy and control

- Extensions can request powerful permissions. Only install add-ons you trust.
- Manage installed add-ons from Menu > Add-ons and themes.
