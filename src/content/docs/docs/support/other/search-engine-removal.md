Waterfox lets you choose from a number of built-in search engines to set as your default (see [Change your default search settings in Waterfox](/docs/support/search/change-default-search) for details). After updating Waterfox, you may notice that your default search engine has changed.

## Why did my search engine change?

From time to time, changes in the upstream codebase we use affect how search engines are implemented in Waterfox. Mozilla frequently modifies the search engine infrastructure, which can impact your default search settings when Waterfox incorporates these upstream changes.

If your default search engine is changed, you'll receive a notification in Waterfox so you can further customize your default search settings.

If you received a notification that your default search engine has changed after updating Waterfox, you can keep the new default or set a search engine of your choice.

## Will I be able to reconfigure my preferred search engines after this change takes place?

If you wish to continue using a search engine that has been removed, you will need to install a third-party search plugin or add-on for that engine.

You can also choose a different default search engine from the available ones:

### Changing Your Default Search Engine

#### Windows and Linux

1. Click the menu button ☰ and select **Settings**.
2. Select **Search** in the left pane.
3. Use the drop-down menu under **Default Search Engine** to change the default search engine.

#### macOS

1. In the Menu bar at the top of the screen, click **Waterfox** and then select **Preferences** or **Settings**, depending on your macOS version.
2. Select **Search** in the left pane.
3. Use the drop-down menu under **Default Search Engine** to change the default search engine.
