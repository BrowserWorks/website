---

First, make sure the add-on is installed, enabled and up to date by checking your installed add-ons.

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" />, click Add-ons and Themes and select Extensions.
2. **Ensure that installation was completed.** If Facebook Container appears on the list, it was successfully installed and you can move on to the next step.
3. **Make sure it is enabled.** If it is disabled, click Enable to activate it.
4. **Update Facebook Container.** See [How to update add-ons](/support/how-update-add-ons)

## I can't install Facebook Container even though I'm on Waterfox 57+

If you're on version 57+ and still unable to install Facebook Container, you might have another extension or configuration that causes Waterfox to conceal its version.

To work around this, copy and paste this link into your address bar: **<https://addons.mozilla.org/firefox/downloads/latest/facebook-container/platform:2/addon-954390-latest.xpi>**.

Waterfox may ask for your permission to install the add-on. If it does, click the **Add** button.

## How do I know if Facebook Container is working?

After you've installed and updated the Facebook Container add-on, open a new tab and enter [facebook.com](http://facebook.com). If the word **Facebook** appears in blue on the right side of the address bar, and the blue underline appears in that tab, then Facebook Container is working properly.

Waterfox created and supports [Facebook Container](https://addons.mozilla.org/firefox/addon/facebook-container/) and [Waterfox Multi-Account Containers](https://addons.mozilla.org/firefox/addon/multi-account-containers/). Other container extensions are not maintained by Waterfox. If you are experiencing issues with these other extensions, please contact the developer directly.

## Affected Facebook features

Facebook Container prevents Facebook from linking your activity on other websites to your Facebook identity. Therefore, the following will not work:

- **“Like” buttons and embedded Facebook comments on other websites** Because you are logged in to Facebook only in the container, “Like” buttons and embedded Facebook comments on other websites will not work.
- **Logging in or creating accounts on other websites using Facebook** Websites that allow you to create an account or log in using Facebook will generally not work properly.
