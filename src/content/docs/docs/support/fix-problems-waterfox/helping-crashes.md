---

If Waterfox crashes, you can help by sharing crash information and details about what you were doing when the crash happened.

## Submit a crash report

- After a crash, the Waterfox Crash Reporter lets you send a crash report. Check “Tell Waterfox about this crash so they can fix it” and include a brief description.
- Enable “Allow Waterfox to submit an additional report” if offered to include technical data that helps diagnose the issue.

## Find your crash report IDs

1. Type `about:crashes` in the address bar and press Enter.
2. Look for links that start with `bp-`. Copy the most recent Report IDs when asking for help.

## Include helpful details

- What you were doing right before the crash (sites, clicks, steps).
- Whether it happens in Troubleshoot Mode (Help > Troubleshoot Mode) with extensions disabled.
- Your Waterfox version and operating system.
