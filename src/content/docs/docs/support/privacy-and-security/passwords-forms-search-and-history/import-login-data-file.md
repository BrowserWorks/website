title: "Import login data from a file"
---

Waterfox introduced a feature in [Waterfox version](/support/find-what-version-waterfox-you-are-using) 80 to let you import login information from a `.csv` (comma separated values) file.

**This feature is currently disabled by default, due to performance issues.**
You can also import other data, such as browsing history and saved passwords, from another browser. See [Import data from another browser](/support/import-data-another-browser).

**Note**: Waterfox does **not** save or sync login data from another browser or file unless you choose to import it. This data is stored locally in a readable form on your computer by the other browser.
