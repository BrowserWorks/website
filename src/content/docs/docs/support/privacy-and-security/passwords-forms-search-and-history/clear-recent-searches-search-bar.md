Waterfox includes a Search bar on the [New Tab page](/support/about-new-tab-page) and an optional [Search bar](/support/add-search-bar-waterfox-toolbar) located to the right of the address bar. When you [search the Web with Waterfox](/support/search-waterfox-address-bar), the Search history can grow quite large over time. This article explains how to clear items from your Waterfox Search history.

- If you want to clear address bar search suggestions, see [Remove websites from the address bar suggestions](/support/remove-websites-address-bar-suggestions).
- If you want to clear search terms on websites, see [Control whether Waterfox automatically fills in forms](/support/control-whether-waterfox-automatically-fills-forms).

## Clearing all search items

1. Click the Library button <img alt="library icon" class="inline-image" src="/assets/docs/icons/library.svg" />, click History and select Clear Recent History… from the History menu.
   ![Fx60Library-ClearRecentHistory](/assets/docs/2019-01-13-14-45-28-34dc81.png)
2. In the dialog box that opens, choose Everything from the _Time range to clear:_ drop-down menu.
   ![Fx63ClearRecentHistory-Search](/assets/docs/2019-01-13-08-42-23-16ed79.png)
3. Make sure that Form & Search History has a check mark next to it and remove check marks for any items you don't want to clear.
4. Click the Clear Now button to finish.

## Clearing individual search items

To clear **individual** items from the Search bar history, click on the Search input field. Press the ↓ and ↑ keys to scroll the list of items. To delete the highlighted item, pressShift+Delete.
