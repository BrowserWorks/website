---

You can import saved passwords into Waterfox from a CSV file exported by another browser or password manager.

## Import from a CSV file

1. Open Menu > Passwords (about:logins).
2. Click the menu in the top‑right of the Passwords page and choose Import from a File.
3. Select your CSV file and confirm.

Notes:
- The CSV file should include columns for website, username, and password. Some formats also include additional fields.
- If Import from a File is not visible, update Waterfox to the latest version.
