---

Waterfox will automatically add and sync your logins if you've enabled logins sync (see [Sync logins in Waterfox desktop](/support/sync-logins-waterfox-desktop)). You can also add logins to Waterfox, if you prefer, by following these steps:

1. Click the Waterfox menu <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> button.
2. Click Logins and Passwords.
   - The Waterfox _about:logins_ page will open.![create login lockwise 70](/assets/docs/2019-09-27-11-33-16-bb1983.png)
3. Click Create New Login at the bottom of the page.
4. Enter the website address, username, and password for that site.
5. Click Save.

To learn more about managing logins in Waterfox, see [Password Manager - Remember, delete and edit logins and passwords in Waterfox](/support/password-manager-remember-delete-edit-logins).
