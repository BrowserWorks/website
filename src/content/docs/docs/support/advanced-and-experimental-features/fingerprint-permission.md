title: "Fingerprinting permission in Waterfox"
---

Waterfox includes protections against browser fingerprinting to reduce cross‑site tracking. Sites do not receive a special permission to fingerprint you.

## What this means

- Waterfox limits high‑entropy APIs and standardizes certain values to make your browser look more like others.
- You may see minor changes in site behavior (for example, reduced precision in timing APIs).

## Control

- Fingerprinting protections are on by default in Waterfox. There is no setting to grant “fingerprinting permission” to a site.
- For more privacy, use Strict privacy settings and Private Windows.
