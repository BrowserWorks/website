---

The Waterfox [cache](http://wikipedia.org/wiki/Web_cache) temporarily stores images, scripts, and other parts of websites you visit in order to speed up your browsing experience. This article describes how to clear the cache.

- To clear your history (cookies, browsing history, cache, etc.) all at once, see [Delete browsing, search and download history on Waterfox](/support/delete-browsing-search-download-history-waterfox).

## Clear the cache

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> and select Settings.
2. Select the Privacy & Security panel.
3. In the **Cookies and Site Data** section, click Clear Data….
   ![Fx91CookiesAndSiteData-ClearCache](/assets/docs/2022-02-07-03-11-15-f71419.png)
4. Remove the check mark in front of **Cookies and Site Data**.
   - For more information about managing site data, see [Manage local site storage settings](/support/storage).
5. With _Cached Web Content_ check marked, click the Clear button.
6. Close the _about:preferences_ page. Any changes you've made will automatically be saved.

:::tip
Here's another way to clear the Waterfox cache:
:::

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> to open the menu panel.
2. Click History and select Clear Recent History….
3. Next to **Time range to clear**, choose **Everything** from the drop-down menu, select **Cache** in the items list, make sure other items you want to keep are not selected and then click the OK button.

See [this article](/support/delete-browsing-search-download-history-waterfox#how-do-i-clear-my-history) for details.

## Automatically clear the cache

You can set Waterfox to automatically clear the cache when Waterfox closes:

1.  Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> and select Settings.
2.  Select the Privacy & Security panel and go to the **History** section.
3.  In the drop-down menu next to **Waterfox will**, choose Use custom settings for history.
    ![Fx100Custom-ClearHistoryWhenWaterfoxCloses](/assets/docs/2022-05-17-18-16-12-63c152.png)
4.  Select the check box for **Clear history when Waterfox closes**.
5.  Click the Settings… button. The _Settings for Clearing History_ window will open.
6.  Put a check mark next to **Cache** and make sure other items you want to keep are not selected.
    ![Fx100SettingsForClearingHistory-Cache](/assets/docs/2022-05-17-18-42-13-97be9c.png)

        * For more information about other settings, see [Delete browsing, search and download history on Waterfox](/support/delete-browsing-search-download-history-waterfox).

7.  Click OK to close the _Settings for Clearing History_ window.
8.  Close the _about:preferences_ page. Any changes you've made will automatically be saved.

**Tip**: There are several add-ons available that allow you to clear the cache using an icon on your toolbar. Go to the [Add-ons Web Page](https://addons.mozilla.org/firefox/) to do a search. Please contact the add-on developer directly if you need assistance with an add-on.
