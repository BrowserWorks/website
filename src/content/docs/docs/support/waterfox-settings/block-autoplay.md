title: "Allow or block media autoplay in Waterfox"
---

Waterfox blocks all media with sound from playing automatically, by default. If you want a website to automatically play media or make other changes to your autoplay settings, you can use one of the methods below.

## Always allow or block media autoplay

To always allow or block autoplay for all media with sound:

1.  Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> and select Settings.
2.  Select the Privacy & Security panel and go down to the _Permissions_ section
    (or enter **autoplay** in the _Find in Options_ search box).
    ![Fx66Permissions-BlockAutoplay](/assets/docs/2019-03-20-02-36-18-113035.png)

    - Block websites from automatically playing sound is the default setting. When check-marked, media autoplay is blocked by default.

    :::note
    If media autoplays on websites by default, even though the setting is check-marked, try clearing the check box and then check-mark it again.
    :::

    - Clear the Block websites from automatically playing sound check box to always allow autoplay by default.

Your selection will apply to all media for all websites, except for autoplay site exceptions.

## Site settings

When Waterfox is actively blocking media with sound on a website, you'll see a special icon <img alt="Fx66BlockAutoplayIcon" class="inline-image" src="/assets/docs/2019-03-20-03-14-47-f0bd84.png"> in the address bar. Click the in the address bar to open the [Control Center](/support/site-information-panel), where you can change the Autoplay sound setting. This option will always appear in the Control Center.

**Note**: You can also change the Autoplay setting for a website from the [Page Info window](/support/waterfox-page-info-window) Permissions panel (uncheck _Use Default_ under **Automatically Play Media with Sound** and select a different setting).

## Manage autoplay site Exceptions

You can add or remove individual websites from your autoplay Exceptions list. To manage the list of sites you have set to block or allow autoplay:

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> and select Settings.
2. Select the Privacy & Security panel and go down to the _Permissions_ section
   (or enter **autoplay** in the _Find in Options_ search box).

3. Find the _Block websites from automatically playing sound_ setting and click Exceptions… to manage your list.

:::note
When adding sites to the list, try using the entire URL for the specific webpage that has media, if the URL for the main website does not work.
:::
