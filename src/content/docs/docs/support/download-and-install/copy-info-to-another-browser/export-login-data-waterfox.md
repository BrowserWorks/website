---

If you want to back up your saved usernames and passwords or move them to a different application, the [Waterfox password management feature](/support/password-manager-remember-delete-edit-logins) allows you to export this data to a `.csv` (comma separated values) file.

:::caution
Your passwords in the exported file will not be encrypted and will be in a readable form to anyone who can view this file. Do not upload online, email or share the exported file. Delete this file when finished.
:::
You can also [import login data from another browser](/support/import-data-another-browser).

## Export usernames and passwords

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> to open the menu panel.
2. Click Logins and Passwords.
   The Waterfox _about:logins_ page will open in a new tab.
3. Click the logins menu icon (three dots), then click Export Logins….
   ![Fx89logins3-dotMenuExport-win](/assets/docs/2021-12-12-05-54-20-83779a.png)
4. A dialog box will appear to remind you that passwords are saved as readable text. Click the Export… button to continue.
   - You may be prompted to enter your [Primary Password](/support/use-primary-password-protect-stored-logins), if enabled, when accessing stored passwords.
5. You can choose the file name and location where this exported data will be saved.
