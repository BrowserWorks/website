---

:::caution
This article applies to Waterfox on Windows.
:::

Waterfox disables background updates on Windows. Updates are checked for and installed only when Waterfox is open.

## How to update Waterfox on Windows

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> at the right side of the Waterfox toolbar, go to Help, and select About Waterfox.
2. Waterfox will check for updates automatically. If an update is available, it will be downloaded.
3. When the download is complete, click Restart to update Waterfox.

## Background updates are disabled in Waterfox

Background updates are not available by design. Waterfox will update only when the browser is open.
