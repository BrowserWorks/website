title: "Wrong home page opens when I start Waterfox - How to fix"
---

Some third-party software providers might change Waterfox's shortcut so that the browser always opens their page. To prevent this from happening, make sure you decline any options to set your site preferences when installing or updating a third-party application.

If the wrong home page keeps opening even when you've taken steps to [remove a toolbar that's taken over Waterfox](/support/remove-toolbar-has-taken-over-your-waterfox-search) and [restored your home page](/support/how-to-set-the-home-page), try checking the Waterfox shortcut:

1. Right-click on the Waterfox icon on your desktop or task bar, then click on Properties.
2. In the _Target:_ field, you'll see the web address that the software provider keeps telling Waterfox to load when you open the browser (for example, "http://bitable.com"). Delete that web address and click OK to save your changes:
