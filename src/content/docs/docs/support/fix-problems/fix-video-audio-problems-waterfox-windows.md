title: "Fix video and audio problems on Waterfox for Windows N editions"
---

Windows versions designated as Windows N and KN editions are missing Windows Media Player and related technologies needed to decode and play videos and music properly. Microsoft offers a _Windows Media Feature Pack_ that you can download and install, to add this functionality.

:::note
Downloads for Windows 7 and earlier Windows versions are no longer available from Microsoft.
:::

Here are some problems that people have reported when the Windows Media Feature Pack is missing:

- "Why is YouTube video blurry, low resolution, or black?"
- "Why doesn't Vimeo work?"
- "Why do I get a Netflix error that Microsoft Silverlight is required?"

## Solution

To resolve this, please install the Media Feature Pack that's appropriate for your version of Windows. See
Microsoft's [support article](http://windows.microsoft.com/windows/which-operating-system) to find your Windows version.

If you update Windows to a newer version, you'll need to install the newer version of the Media Feature Pack even though you installed it for the previous Windows version.
**Windows 11**:

On Windows 11 the latest Media Feature Pack can be added as an Optional Feature from Windows Settings. To add the Media Feature Pack:
Select the **Start** button, then select **Settings** > **Apps** > **Optional features**. Select **View features** next to **Add an optional feature**, and then select the **Media Feature Pack** in the list of available optional features. For more information, see [Microsoft's Media Feature Pack article](https://support.microsoft.com/en-us/windows/media-feature-pack-for-windows-n-8622b390-4ce6-43c9-9b42-549e5328e407).

**Windows 10**:

On Windows 10 version 1903 (May 2019) and later, the latest Media Feature Pack can be added as an Optional Feature from Windows Settings. To add the Media Feature Pack:
Select the **Start** button, then select **Settings** > **Apps** > **Apps and Features** > **Optional features** > **Add a feature**. Find the **Media Feature Pack** in the list of available optional features. For more information, see [Microsoft's Media Feature Pack article](https://support.microsoft.com/en-us/windows/media-feature-pack-for-windows-n-8622b390-4ce6-43c9-9b42-549e5328e407).

To download the Media Feature Pack for earlier Windows 10 versions and for information about all available Media Feature Packs, see Microsoft's [Media Feature Pack list for Windows N editions](https://support.microsoft.com/en-us/help/3145500/media-feature-pack-list-for-windows-n-editions).

**Windows 8.1**:

- [Windows 8.1: N and KN editions](http://www.microsoft.com/download/details.aspx?id=42503) (Microsoft Support article [KB2929699](https://support.microsoft.com/en-us/kb/2929699))

**Windows 8**:

- [Windows 8: N and KN editions](http://www.microsoft.com/download/details.aspx?id=30685) (Microsoft Support article [KB2703761](https://support.microsoft.com/en-us/kb/2703761))
