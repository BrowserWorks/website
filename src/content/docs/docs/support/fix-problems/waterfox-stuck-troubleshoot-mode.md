---

This article describes why Waterfox may start in Safe Mode when you expect it to start normally and how to fix the problem.

- See the [Diagnose Waterfox issues using Troubleshoot Mode](/support/diagnose-waterfox-issues-using-troubleshoot-mode) article for information about using this special startup mode to fix Waterfox problems.

If you started Waterfox in Safe Mode, it will remain in Safe Mode until Waterfox is completely closed. The easiest way to make sure Waterfox is completely closed is to restart your computer. Once your computer starts up again, start up Waterfox.

When Waterfox crashes at startup, the next time you launch Waterfox it displays the [Safe Mode window](/support/diagnose-waterfox-issues-using-troubleshoot-mode#11troubleshoot-modesf12safe-modesf-window). This lets you choose between starting in Waterfox Safe Mode or [refreshing Waterfox](/support/refresh-waterfox-reset-add-ons-and-settings) because you may have something wrong with your configuration (such as graphics, add-ons, or third-party software). See [Troubleshoot Waterfox crashes (closing or quitting unexpectedly)](/support/troubleshoot-waterfox-crashes-closing-or-quitting) for help solving crashes when starting Waterfox.
