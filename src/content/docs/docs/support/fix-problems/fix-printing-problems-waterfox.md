This article describes how to troubleshoot printing problems in Waterfox. For general information about printing in Waterfox, see [How to print web pages in Waterfox](/support/how-print-web-pages-waterfox).

## Check other browsers and printers

You can see whether your problem is with Waterfox, your printer or the website you're visiting:

- Check to see whether the page prints correctly in another browser (such as Internet Explorer or Microsoft Edge).

If the page prints incorrectly in another browser also, then:

- There might be a problem with your printer.
  If you have another printer, try printing the page with that printer. If the second printer prints the page properly, update your printer driver from your printer manufacturer's website.
- There might be a problem with the page.
  Contact the website administrator.

If the page prints correctly in another browser, follow the instructions below:

## Reset Waterfox printer settings

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" />, click Help and select More Troubleshooting Information.
   - The Troubleshooting Information page with the address _about:support_ will open in a new tab.
2. Go down to the **Printing** section and click Clear saved print settings.

This will remove all modified print settings in Waterfox.
