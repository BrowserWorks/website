title: "Home page with pipe character opens extra tabs when Waterfox starts"
---

Waterfox sets multiple [home pages](/support/how-to-set-the-home-page) when you separate each address with a pipe character (|) or vertical bar. This feature may lead to problems when an individual home page address contains a pipe character.

Here's how to fix it:

1. Click the menu button <img alt="menu button" class="inline-image" src="/assets/docs/icons/menu.svg" /> and select Settings.
2. Select the General panel.
3. In the **Home Page** text box, replace all pipes (|) with **%7C**.
4. Close the _about:preferences_ page. Any changes you've made will automatically be saved.

:::tip
If removing the pipe character doesn't solve the problem, add-ons or malware might be causing this behavior. Try [refreshing Waterfox](/support/refresh-waterfox-reset-add-ons-and-settings) to remove add-ons without erasing your browsing information and bookmarks.
:::
