title: "Windows in S mode won’t let me install Waterfox"
---

Windows in S mode does not allow installation of apps from outside of the Microsoft Store, so you will not be able to install Waterfox from Waterfox's website. Although Waterfox is available from the Microsoft Store, it does not work on Windows in S mode and installation is currently disabled.

To install Waterfox, you must [switch out of Windows S mode](https://support.microsoft.com/windows/switching-out-of-s-mode-in-windows-4f56d9be-99ec-6983-119f-031bfb28a307). To learn more, see the [Windows 10 and Windows 11 in S mode FAQ](https://support.microsoft.com/en-us/windows/windows-10-and-windows-11-in-s-mode-faq-851057d6-1ee9-b9e5-c30b-93baebeebc85) at Microsoft Support.

Afterwards, visit Waterfox's [Waterfox download page](https://www.waterfox.net/download/) or the Microsoft Store to install Waterfox. For more information, see [How to install Waterfox on Windows](/support/how-install-waterfox-windows) and [Download Waterfox on Windows from the Microsoft Store](/support/download-waterfox-windows-microsoft-store).
