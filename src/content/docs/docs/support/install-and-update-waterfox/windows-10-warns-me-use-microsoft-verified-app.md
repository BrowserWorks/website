title: 'Windows 10 warns me to use a "Microsoft-verified" app'
---

In certain versions of Windows 10, you may receive a notification with a warning about _Microsoft-verified apps_ when you run the Waterfox installer.

![Windows 10 dialog box](/assets/docs/2020-09-18-10-47-06-7f0552.png)

**Any copy of Waterfox downloaded from www.waterfox.net is safe to install**, so choose "_Install anyway_".

:::note

:::

- You can also [download and install Waterfox from the Microsoft Store](/support/download-waterfox-windows-microsoft-store).
- **Using Windows 10 in S mode?** See [Windows in S mode won't let me install Waterfox](/support/windows-s-mode-wont-let-me-install-waterfox).

If you do not see the option to “_Install anyway_”, follow the steps below to change your system settings.

1. Open the Windows 10 start menu and select **Settings**.
   ![Windows 10 start menu](/assets/docs/2020-09-18-10-51-18-9b6441.png)
2. Click on **Apps** in the _Windows Settings_ menu.
   ![win10-settings-apps](/assets/docs/2020-09-21-17-00-28-af2077.png)
3. In the _Apps & features_ section go to **Choose where to get apps**, click on the dropdown menu below and select one of the options that allows you to install from _Anywhere_.
   ![win10-settings-apps-store](/assets/docs/2020-09-21-17-01-00-7ce375.png)
4. Run the Waterfox Installer again. Your Windows may now allow it to install Waterfox.
