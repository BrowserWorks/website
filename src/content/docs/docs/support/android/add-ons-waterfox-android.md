Add-ons (also called “extensions”) let you customize Waterfox for Android with extra features like content blocking, password management, and more.

## Find and install add-ons

You can install add-ons from the Firefox Add-ons website (AMO)

- Install from the website
  1. Open the [Firefox Add-ons website](https://addons.mozilla.org/android/).
  2. Browse or search for an add-on that supports Android.
  3. Tap the add-on to view details, then tap Add to Waterfox.
  4. Review the requested permissions and confirm to install.
  5. After installing, choose whether to Allow in private browsing (you can change this later).

Note: Some add-ons are not compatible with Waterfox for Android, but you will still be able to install them.

## Update, change options, or remove add-ons

- Update add-ons
  - Waterfox will automatically update your add-ons to compatible versions when available.

- Temporarily disable or remove an add-on
  1. Tap the menu button.
  2. Tap Add-ons.
  3. Under Enabled, find the add-on you want to change and tap it.
  4. To disable: Toggle the Enabled switch off. To uninstall: Tap Remove.

- View or change an add-on’s settings
  - From the add-on’s page, you can view/edit Settings, Details, and Permissions, if provided by the add-on.

## Enable add-ons in private browsing

Add-ons are disabled by default in private browsing. To change this:
1. Tap the menu button.
2. Tap Add-ons.
3. Tap the add-on you want to allow (or disallow).
4. Toggle Run in private browsing on or off.

## Troubleshooting

- The add-on doesn’t work on a specific site
  - Check the add-on’s settings or site permissions and try reloading the page.
