Add-ons let you customize Waterfox for Android with extra features like ad blocking, password management, and more.

## Browse and install add-ons

1. Go to the [Firefox Add-on Store](https://addons.mozilla.org)
2. Browse the recommended add-ons list or search.
3. Tap an add-on to see details, then tap Add to Waterfox.
4. Review permissions and confirm to install.

## Manage installed add-ons

- Open Menu > Exensions to enable/disable or remove an add-on.
- Tap an add-on to configure its options, if provided.
- Some add-ons place a button in the address bar or menu for quick access.

## Permissions

When installing, Waterfox will show the permissions the add-on requests. Only install add-ons you trust. See [Permission request messages for Waterfox extensions](/support/permission-request-messages-waterfox-extensions) to learn what each permission means.

## Troubleshooting

- An add-on isn’t compatible
  - Some desktop add-ons are not available on Android. Look for Android‑compatible alternatives on Firefox Add-ons.
- The add-on doesn’t work on a specific site
  - Check the add-on’s settings or site permissions; try reloading the page.
- I want to remove an add-on
  - Open Menu > Add-ons, tap the add-on, and choose Remove.
