### Fixes

- Latest security fixes[^1].
- Vertical Tabs improvements:
  - Better favicon handling and loading performance
  - Better handling with the bookmarks sidebar and library windows
  - Fixed issues with popup menus and tab previews
  - Improved stability for private browsing windows
  - Enhanced drag-and-drop behavior for moving tabs

:::tip[Waterfox Private Search - Open Beta]
We've recently launched Waterfox Private Search in open beta! This new meta-search engine is designed to provide a more private search experience with no tracking, no AI summaries stealing content from websites, and no annoying pop-ups or banners.

You can try it now at [search.waterfox.net](https://search.waterfox.net) and read more about it in our [announcement post](/blog/waterfox-private-search).

Your feedback during this beta period will be invaluable as we work toward making this our default search option in future releases.
:::
