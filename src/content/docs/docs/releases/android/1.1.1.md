## Bug Fixes

- **Fixed DuckDuckGo default search engine issue** - Users can now properly set DuckDuckGo as their default search engine

## New Features

- **Added Quit button to menu** - You can now easily quit the application from the main menu
- **Menu redesign toggle** - Added option to switch between the new menu design and the classic menu layout (Settings > General > Customize > Enable Menu Redesign)
