This update adds Ukrainian as a UI language, a new quality-of-life feature and the latest security fixes.

## New

- Added Ukrainian locale
- Added the ability to copy current tab url to your clipboard with: [<Badge text="Thanks @evilurge" variant="tip" />](https://github.com/evilurge/quick-url-copy)
  - macOS: Command + Shift + U
  - Windows/Linux: Ctrl + Shift + U

## Fixed
- All [security advisories](https://www.mozilla.org/en-US/security/advisories/mfsa2025-89/) part of MFSA2025-89.
